How It Works
From Code to Report in ~9 Seconds
1
📂
Load via Office Kit
Load a code file via iQOO Office Kit file picker, or paste directly. Supports .py, .js, .java, .kt, .ts, .go, .cpp
2
⚡
Phi-3 Scans On-Device
MediaPipe LLM Inference runs Phi-3 Mini on the Snapdragon NPU. Code is processed in memory — never written to disk, never transmitted
3
🔴
Severity-Ranked Report
Color-coded findings: HIGH · MED · LOW. Each card shows line number, description, and a specific code fix suggestion
Tested in airplane mode. Not a single byte of code left the phone.
